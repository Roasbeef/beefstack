# Fields by verb

Fields grouped by the verb they are good at, each with the procedure it runs
and the artifact it returns. Use the verbs from step 2 of the skill to pick
rows. These are starting points; a task's verbs may call for a field not
listed here.

## Persuade and decide

- **Journalist.** Finds the single most important verified fact and leads
  with it; writes a lede and nut graf. Artifact: the opening plus sources.
- **Editor.** Cuts length by a third, reorders by reader priority, removes
  claims the piece does not need. Artifact: the cut draft and a list of cuts.
- **Trial lawyer.** Prepares for cross-examination: lists the questions an
  opponent would ask and the evidence each answer needs. Artifact: a
  question-and-evidence table.
- **Triage (ER triage nurse, incident commander).** Ranks items by risk
  against the attention each costs, so a reader with little time spends it
  where it matters. Artifact: an ordered list with a time budget per item.
- **Decision analyst.** Turns open questions into decisions with options,
  arguments for and against, reversibility, and what would change the call.
  Artifact: a decision table.

## Explain and teach

- **Teacher.** Lists the misconceptions a newcomer brings and builds one
  worked example that corrects them. Artifact: misconception list and
  example.
- **Information designer.** Finds the one mechanism the reader must see and
  draws it. Artifact: a diagram.
- **Documentarian.** Orders the material as a sequence of scenes with a
  through-line. Artifact: a scene outline.

## Break and defend

- **Attacker.** Writes a concrete exploit sequence and runs it. Artifact: a
  reproduction or the specific thing that blocked it.
- **Short seller.** Builds the case against the claim from primary sources
  the main story leaves out. Artifact: a short thesis with citations.
- **Forensic accountant.** Reconciles the numbers from independent sources
  and flags any that do not tie out. Artifact: a reconciliation table.
- **Safety engineer.** Runs a failure modes and effects analysis (FMEA):
  each component, how it fails, the effect, the detection. Artifact: an FMEA
  table.
- **Chaos engineer.** Injects faults (kill, partition, delay, disk full) and
  records what breaks. Artifact: a fault-injection report.

## Build reliably

- **SRE.** Defines the service level, the signals that show it, and the
  runbook for each alert. Artifact: SLOs and runbooks.
- **Formal methods.** Models the state machine and checks invariants
  mechanically. Artifact: the model and the checker output.
- **Test engineer.** Derives properties and edge cases from the invariants,
  then writes property-based tests. Artifact: tests and the properties list.
- **Release manager.** Plans rollout, compatibility, and rollback. Artifact:
  a rollout plan with a rollback trigger.

## Measure and predict

- **Statistician.** Picks the model, checks assumptions, reports intervals
  instead of point estimates. Artifact: the analysis with uncertainty.
- **Epidemiologist.** Defines cohorts, looks for confounders, separates
  correlation from cause. Artifact: a cohort analysis.
- **Forecaster.** Starts from base rates, then adjusts for the specifics.
  Artifact: a forecast with its reference class.
- **Economist.** Maps the incentives and fee or cost structure each party
  faces. Artifact: an incentive map.

## Design for people

- **UX researcher.** Writes the user's task step by step and finds where it
  breaks. Artifact: a task analysis with failure points.
- **Accessibility specialist.** Audits contrast, keyboard paths, and screen
  reader output. Artifact: an audit list.
- **Motion and audio designer.** For presented work, plans the pacing and
  transitions that carry the argument. Artifact: a timed storyboard.

## Coordinate many parties

- **Standards editor.** Finds every requirement with two plausible readings.
  Artifact: an ambiguity table.
- **Game theorist.** Enumerates each party's actions and payoffs and finds
  profitable deviations. Artifact: a deviation table.
- **Mechanism designer.** Changes the rules so the desired behavior is each
  party's best response. Artifact: a revised rule set with the argument.
- **Negotiator.** States each party's interests and best alternative to
  agreement, and where they overlap. Artifact: an interests map.

## The role-play test

Before keeping any field, ask: what does this field's artifact contain that
the obvious field's output would not? If the answer is "the same content in a
different voice", strike it. A short seller is kept for a thesis built
from footnotes, not for a skeptical tone.
