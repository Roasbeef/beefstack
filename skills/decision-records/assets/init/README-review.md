# Review waves

One file per reviewer per wave (`<wave>-<surface>.md`) and one triage
roll-up (`<wave>-triage.md`) with a FIX / DOC / DEFER / DISMISS
disposition per finding. These are records of what a reviewer saw at a
commit and are never re-pinned to a later tree; only the triage file's
"Where this stands" section is updated as fixes land.
