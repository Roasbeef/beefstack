# Design notes

Explorations and pre-code rulings: thinking too long for an issue and too
provisional for an ADR. Each note opens with a `Status:` line that moves
as the note does (`note, not a work package` → `ruling, pre-code` → `built`).
A note is never deleted because its work landed; the outliving decisions
go to an ADR that cites it, and the note keeps the argument.
