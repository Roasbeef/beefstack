# Architecture decision records

A decision whose consequences outlive one change lives here: a storage
binding, a wire format, a security boundary, a pooling granularity.
Files are `NNN-<the-ruling-as-a-slug>.md`, numbered once and never
renumbered. An ADR is amended by an addendum appended inside it, never by
editing the ruling; superseding one is a new ADR whose `Supersedes` line
names the old.
